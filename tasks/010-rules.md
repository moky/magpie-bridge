## 缩略词

全局名词解析：

| Name | Desc                                |
|------|-------------------------------------|
| MP   | MagPie, Magpie Protocol, Message Protocol, Message Packet |
| BID  | Bridge ID （注册号/门牌号）            |
| DSN  | Data Serial Number （数据/文件序列号） |
| SYN  | 握手（建立连接）                      |
| FIN  | 挥手（结束连接）                      |
| ACK  | 应答                                |
| MSS  | Maximum Segment Size               |
| MTU  | Maximum Transmission Unit          |
